# Sovu Hello World

Pipeline test module for Foundry VTT V14: whispers a greeting to the GM when a world loads.

## Install
Foundry → Add-on Modules → Install Module → Manifest URL:

```
https://github.com/sovu1games/SovuHelloWorld/releases/latest/download/module.json
```

## Settings
- **Greet on load** (world): whisper the greeting to the GM when the world loads. On by default.
